phpThumb
========

phpThumb() - The PHP thumbnail generator

phpThumb() uses the GD library and/or ImageMagick to create thumbnails from images (GIF, PNG or JPEG) on the fly.
The output size is configurable (can be larger or smaller than the source), and the source may be the entire
image or only a portion of the original image. True color and resampling is used if GD v2.0+ is available,
otherwise low-color and simple resizing is used. Source image can be a physical file on the server or can be
retrieved from a database. GIFs are supported on all versions of GD even if GD does not have native GIF support
thanks to the GIFutil class by Fabien Ezber. AntiHotlinking feature prevents other people from using your server
to resize their thumbnails, or link to your images from another server. The cache feature reduces server load.

Files taken as they are from upstream: phpthumb.functions.php, phpthumb.filters.php, phpthumb.gif.php,
phpthumb.bmp.php, phpthumb.ico.php, phpthumb.unsharp.php, license.txt, fonts/, images/.

FLEXIcontent changes to upstream files (re-apply them when updating the library):

- phpThumb.php: the two lines forcing `error_reporting(E_ALL)` and `display_errors` are commented out.
- phpthumb.class.php: a default timezone (UTC) is set when php.ini has none, and `config_cache_directory`
  is coerced to a string before `substr()` (PHP 8.1+ deprecation).
- phpThumb.config.php: FLEXIcontent's own configuration (not upstream's phpThumb.config.php.default); it can
  be included more than once, and it loads the two files described below.

Configuration layering
----------------------

1. `phpThumb.config.php` - shipped defaults, overwritten by FLEXIcontent updates.
2. `phpThumb.config_FLEXI.php` - generated by FLEXIcontent (component configuration, "phpThumb thumbnails" tab):
   the `high_security_enabled` flag and the random `high_security_password` used to sign thumbnail URLs.
   Never edit it, never ship it, keep it private, back it up with the site.
3. `phpThumb.config_OVERRIDE.php` - manual per-site overrides, created empty by FLEXIcontent and never touched
   afterwards. Loaded last, so it wins. Only assign `$PHPTHUMB_CONFIG[...]` values in it: the file is also
   included inside Joomla (image field, URL signing), so it must not produce output or exit.

Signed URLs
-----------

FLEXIcontent signs every phpThumb URL it generates with `flexicontent_images::phpThumbURL()`
(components/com_flexicontent/classes/helpers/images.php). When "Enforce signed thumbnail URLs" is enabled in the
component configuration, phpThumb.php refuses URLs without a valid `hash` parameter, so visitors cannot request
arbitrary source files, remote URLs, filters or sizes. Custom templates and modules should build their URLs
with the same helper, for example:

    echo '<img src="' . flexicontent_images::phpThumbURL(array(
        'src' => 'images/pic.jpg',   // relative to the site root, root-relative, or an absolute URL
        'w'   => 200,
        'h'   => 150,
        'zc'  => 1,
        'q'   => 95,
        'ar'  => 'x',
        'f'   => flexicontent_images::phpThumbFormat('images/pic.jpg'),
    )) . '" alt="" />';

The helper returns an HTML-escaped URL by default; pass `false` as second argument for a raw URL (JSON,
JavaScript) and `true` as third argument for an absolute URL (feeds, e-mails). While "Sign legacy thumbnail
URLs" is enabled, the FLEXIcontent system plugin also signs unsigned phpThumb.php URLs found in rendered pages,
so existing templates keep working after enforcement is switched on.
